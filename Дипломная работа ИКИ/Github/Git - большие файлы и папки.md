
## Ограничения GitHub (free)
- **Файл:** жёсткий лимит 100 МБ (push отклонит), предупреждения с 50 МБ.
- **LFS:** 1 ГБ хранилища + 1 ГБ трафика в месяц.
- **Репозиторий:** рекомендация ≤ 1 ГБ, мягкий предел ~5 ГБ.
- **Главное:** `.gitignore` влияет ТОЛЬКО на файлы, которые ещё не были закоммичены. На уже отслеживаемые — нет.

## Сценарий 1. Папка ещё НЕ была в коммитах
1. Добавить в `.gitignore` строку:
   ```
   папка/
   ```
2. ```
   git add -A
   git commit -m "..."
   git push
   ```

## Сценарий 2. Папка уже отслеживается — отвязать от git (файлы остаются на диске)
```
git rm -r --cached "путь/к/папке"
echo "папка/" >> .gitignore
git add -A
git commit -m "exclude big folder"
git push
```
⚠️ Папка исчезнет из новых коммитов, но **останется в истории — размер репо не уменьшится**. Для этого — сценарий 3.

## Сценарий 3. Вычистить папку из истории (уменьшить размер репо)
1. `pip install git-filter-repo`
2. ```
   git filter-repo --invert-paths --path "путь/к/папке" --force
   ```
   (можно несколько `--path`; `--force` — если репо не fresh clone)
3. filter-repo сбрасывает remote — вернуть:
   ```
   git remote add origin https://github.com/USER/REPO.git
   ```
4. ```
   git push -f origin main
   ```
5. Добавить папку в `.gitignore`, не вернулась.

**Последствия:** история переписана; на других машинах — только переклонировать заново; GitHub освободит место после фоновой GC (до пары недель).

## LFS: пуш ругается на missing object
Симптом: `(missing) ... missing or corrupt local objects`, `Uploading LFS objects: 0%`.
Причина: в истории есть LFS-указатель, а самого объекта нет локально.

- Посмотреть: `git lfs ls-files` (`-` = объекта нет).
- Объект есть на сервере: `git lfs fetch --all origin && git push`
- Оригинал файла сохранился: положить на то же место, `git add "файл"`, `git push` (файл должен быть байт-в-байт тот же).
- Файл потерян/не нужен: **сценарий 3** (вычистить из истории).
- ⚠️ `git config lfs.allowincompletepush true` отключает только локальную проверку — GitHub всё равно отклонит пуш (ошибка GH008).

## Быстрые проверки
- Отслеживается ли? `git ls-files "путь"` (пусто = не отслеживается)
- Игнорируется ли? `git check-ignore -v "путь"`

## Правила на будущее
- Большие файлы (модели, датасеты, `*.hdf5`) — сразу в `.gitignore`.
- Сначала `git rm -r --cached` + `.gitignore`, потом коммит — иначе игнор не подействует.
- Пути с пробелами/кириллицей — всегда в кавычках.
