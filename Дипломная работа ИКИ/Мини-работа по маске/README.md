## 3. Маски: итог поиска и решение

Подробный обзор со всеми ссылками — [[Источники масок (обзор поиска)]].

> [!summary] Вывод и решение
> Готовых пиксельных масок под SOHO/MDI в открытом доступе **нет**.
> Принята полуавтоматическая схема: pseudo-маски калиброванным пороговым алгоритмом
> (пороги калиброваны по каталогу SDD, Debrecen) + визуальный контроль оверлеями
> + будущая ручная правка 100–300 кадров для val/test ([[Ручная правка]]).

| Слой | Примеры | Роль у нас |
|---|---|---|
| Каталоги по тем же MDI | SDD (Debrecen, 1996–2010), ASSA (KSWC/CCMC), SFC (EGSO), Meadows 2025, Sunspotter/SMART | валидация площадей/позиций |
| Алгоритмы сегментации MDI | ASAP, Turmon 2002, Goel 2014, Meadows 2025, Chen 2025, SATIRE | основа и цитирование порогов |
| Готовые ML-маски | только SDO/HMI (после 2010) | отладка пайплайна, опционально |

## 5. Принципы и ограничения

- Генерация масок — CPU (10k кадров × 1024² ≈ часы); GPU (4 GB VRAM) — только обучение сети.
- Интерполированные/битые кадры (`flat`, `dip`) не попадают ни в один split.
- Пороги — только с цитированием и калибровкой по SDD; параметры — в конфиге генератора;
  версия масок = версия генератора (v0/v0.1/v0.2 задокументированы в [[Генератор масок]]).
- Test-набор после ручной правки заморожен; автоправок в него не вносим.
- Известные систематики масок (писать в раздел валидации диплома): umbra −20…−25% к контуру
  SAM SDD медианно (янв. 12–16 ×1.6); поры <15 px и лимб r>0.99 R в маски не входят.
