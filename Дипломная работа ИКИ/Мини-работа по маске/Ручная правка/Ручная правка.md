# Ручная правка val/test

> [!info] Мета
> Шаг 5 мини-работы (ожидает). Цель: чистый val/test для честных метрик сети и для раздела
> валидации диплома. Связано: [[Датасет]], [[Сверка SDD]], [[Генератор масок]].

## 1. Объём и отбор кадров
- 100–300 кадров из val/test, стратифицированно:
  1) top-30 по |ratio−1| из `sdd/sdd_match.csv` (расхождение маски с SDD);
  2) 10–15 кадров jan 12–18 (epoch-аномалия umbra);
  3) 10–15 кадров с пятнами у лимба (r/R 0.8–0.99);
  4) 20–30 тихих кадров с порами (контроль ложных срабатываний);
  5) остальные — случайная выборка по месяцам.

## 2. Инструмент и протокол
- Инструмент: Label Studio / CVAT / самописный просмотрщик matplotlib (на выбор; самописный проще
  для классов 0/1/2 и FITS-входа).
- Правим только val/test; train остаётся на pseudo-labels v0.2 (схема Chen 2025).
- Каждая правка логируется: trec, класс, площадь до/после, причина (penumbra-граница / umbra-ядро /
  ложное срабатывание / пропуск).
- После правки test заморожен; версии ручных масок: `manual_v1`.

## 3. Метрики приёмки сети (на ручном test)
- IoU и Dice по классам spot (1+2) и umbra (2) отдельно; boundary F1 (допуск 2 px);
- сравнение площадей: median ratio mask_net/manual ∈ [0.85, 1.15] для spot.
