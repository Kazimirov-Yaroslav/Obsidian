> Статус: **v0.2 заморожен** 2026-09-30 после валидации по SDD ([[Сверка SDD]]).
> Выход: `Mask/masks/masks_fits/*.fits` + `Mask/masks/manifest_masks.csv`.

## 1. Пайплайн (актуальный, v0.2)

1. Диск по WCS: r ≤ 0.99·R_sun.
2. Нормировка кадра: `img /= median(img[disk])` (множитель пишется в `qs_norm`).
3. QC per-frame: `flat` (размах I по диску < 0.05); QC post-pass: `dip` (провал относительно ±3 соседей).
4. spot = (I < T_SPOT) & disk → чистка: компоненты < 15 px убрать, дыры залить.
5. umbra = (I < T_UMBRA) & spot → чистка: компоненты < 5 px убрать, дыры залить.
6. Классы: 0 = QS/фон, 1 = penumbra, 2 = umbra; сжатый uint8 FITS; счётчики в манифест.

## 2. Конфиг v0.2 (цитированный)

| Параметр | Значение | Основание |
|---|---|---|
| T_SPOT | 0.96 | калибровка по SDD: median ratio(spot/SDD U+P) ≈ 1.0 между 0.95→0.92 и 0.97→1.07; 0.99 запрещён (захват грануляции, ratio 33) |
| T_UMBRA | 0.65 | компромисс эпох: jan-оптимум ≈0.55, jul–dec ≈0.65–0.70; доля umbra 15–20% физична |
| min_area spot / umbra | 15 / 5 px | ≈10 MSH — предел детектирования MDI/SDD (arXiv:1603.05870) |
| disk_r_frac | 0.99 | шум лимба + форшортенинг |
| нормировка | median(disk) | аппаратный дрейф шкалы (qs_norm 0.9985–1.0009) |

Пороговые семейства и литература — [[Источники масок (обзор поиска)]] (ASAP, Turmon 2002,
Goel 2014, Meadows 2025, Chen 2025, SATIRE).
