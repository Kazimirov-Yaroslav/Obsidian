# 🧠 Словарь терминов нейросетей

> [!abstract] Описание
> Автоматический словарь терминов для диплома.
> Термины хранятся отдельными заметками с тегом `#ml/dictionary`.
> Сортировка выполняется автоматически по полю `term`.

## 📑 Список терминов

```dataview
TABLE WITHOUT ID
  file.link AS "Термин",
  aliases AS "Альтернативные названия",
  category AS "Категория"
FROM #ml/dictionary
SORT term ASC
