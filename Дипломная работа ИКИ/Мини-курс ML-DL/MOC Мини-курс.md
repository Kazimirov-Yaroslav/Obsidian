# Мини-курс ML-DL для диплома по Солнцу

> [!abstract] Назначение курса
> Фундаментальный и прикладной курс по машинному обучению и глубокому обучению, построенный вокруг задачи восстановления магнитного поля Солнца по изображениям в видимом свете и сегментации солнечных пятен.

## 🎯 Цели курса

1. **Дать transferable ML/DL-фундамент**
   - Математическая база: линейная алгебра, матан, теория вероятностей, оптимизация
   - Концептуальное понимание: энкодеры, латентные пространства, градиентный спуск
   - Возможность брать любые задачи в будущем

2. **Специализироваться на Computer Vision и солнечной задаче**
   - CNN, U-Net, Autoencoders, Pix2Pix/GAN
   - Segmentation losses, physics-informed losses
   - Работа с лимбом, магнитограммами, солнечными пятнами

3. **Учесть жесткие ограничения железа**
   - GTX 1650 4 GB VRAM, 8 GB RAM
   - Патчи, gradient accumulation, AMP, lightweight-архитектуры

## ⚙️ Ограничения железа

| Компонент | Характеристика | Следствие для курса |
|---|---|---|
| GPU | GTX 1650, 4 GB VRAM | Маленькие батчи, патчи 128–256 px, gradient accumulation, AMP |
| RAM | 8 GB | Нельзя держать в памяти весь датасет в сыром виде |
| CPU | i5-10500H | Осторожно с `num_workers`, лучше 0–2 |
| SSD | 256 GB | Нужна компрессия и разумное кэширование патчей |
