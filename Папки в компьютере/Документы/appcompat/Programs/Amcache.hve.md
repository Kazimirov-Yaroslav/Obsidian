## 🎯 Назначение

**Основной файл кэша приложений (Amcache)** — база данных всех запущенных программ.

### Что такое Amcache:
**Amcache** (Application Compatibility Cache) — это системная база данных Windows, которая хранит полную информацию о всех приложениях, которые когда-либо запускались на компьютере.

### Что содержит:
- **Полный список запущенных программ** — все .exe файлы, которые когда-либо запускались
- **Даты запуска** — первый и последний запуск каждого приложения
- **Версии файлов** — точные версии исполняемых файлов
- **Хэши файлов** — SHA-1 хэши для идентификации
- **Пути к файлам** — полное расположение каждого приложения
- **Данные о совместимости** — применённые настройки совместимости
- **Сведения об установке** — MSI-пакеты, установщики

## 🔍 Детали

### Формат HVE:
- **Hive file** — формат хранения данных реестра Windows
- Двоичный формат, не открывается в текстовом редакторе
- Структурированное хранилище данных
- Аналог файлов реестра SYSTEM, SOFTWARE и т.д.

- Периодически по расписанию системы

## ⚠️ Безопасность

### Можно ли удалять?
**❌ НЕТ!** Критически важный системный файл.

### Почему нельзя:
- Содержит полную историю запуска программ
- Необходим для работы Program Compatibility Assistant
- Используется при диагностике проблем
- Удаление сбросит всю историю совместимости
- Windows пересоздаст файл, но история будет потеряна

### Что будет при удалении:
- ⚠️ Потеряется история всех запусков программ
- ️ Сброс настроек совместимости
- ⚠️ Возможны проблемы с запуском старых программ
- ⚠️ Windows создаст новый пустой файл

##  Рекомендации

**Не трогать** — это важнейший файл диагностики системы.

### Интересные факты:
- Файл используется в **форензике** (расследовании инцидентов)
- По нему можно определить, какие программы запускались на компьютере
- Помогает выявить вредоносное ПО по истории запусков
- Размер растёт со временем по мере использования компьютера
