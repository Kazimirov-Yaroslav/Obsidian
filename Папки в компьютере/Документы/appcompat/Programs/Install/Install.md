##  Расшифровка имён файлов

### Структура имени:

| Элемент | Часть в имени | Описание |
|---------|---------------|----------|
| **Префикс** | `INSTALL` | Префикс — указывает на журнал установки |
| **Категория установки** | `0000` / `0001` | Категория/тип установки |
| **UUID установки (GUID)** | `0df9a424-414b-497b-adf8-bcdab4d6ef03` | Уникальный идентификатор конкретной установки |

**Полный пример:** `INSTALL_0000_0df9a424-414b-497b-adf8-bcdab4d6ef03`

---

### Категории установок:

#### **0000** — Основные установки
- Стандартные установки программ
- Обновления Windows
- Установки через Windows Installer (MSI)
- Большинство файлов в папке относятся к этой категории

#### **0001** — Дополнительные установки
- Вторичные компоненты
- Дополнительные модули
- Патчи и хотфиксы
- Встречаются реже

---

### UUID (GUID) установки:

Каждый файл имеет уникальный идентификатор в формате GUID:

| Часть UUID | Позиция | Описание |
|------------|---------|----------|
| **Временная метка** | Первые 8 цифр | Основная часть, основанная на времени создания |
| **Версия UUID** | Следующие 4 цифры | Указывает версию UUID (обычно версия 4 — случайный) |
| **Вариант UUID** | Следующие 4 цифры | Указывает вариант UUID |
| **Уникальные данные** | Последние 12 цифр | Уникальный идентификатор узла или случайные данные |

**Пример разбора:** `0df9a424-414b-497b-adf8-bcdab4d6ef03`

**Что это даёт:**
- Каждый GUID уникален для конкретной установки
- Позволяет отслеживать историю каждой установки
- Связывает файл с записью в реестре Windows
- Используется Windows Installer для идентификации

---

## 📄 Что содержат файлы

### Типичное содержимое:
- **Данные установки** — что было установлено
- **Версия программы** — точная версия
- **Дата и время** — когда произошла установка
- **Путь установки** — куда установлена программа
- **Компоненты** — какие компоненты были установлены
- **Зависимости** — необходимые компоненты
- **Статус** — успешна ли установка

### Формат:
- Текстовый файл (читается в блокноте)
- Может содержать XML-разметку
- Иногда — простой текст с параметрами
- Кодировка: обычно UTF-8 или ANSI

## ⚠️ Безопасность

### Можно ли удалять?
**❌ НЕТ!** Системные файлы журналов установок.

### Почему нельзя:
- Необходимы для отслеживания истории установок
- Используются Program Compatibility Assistant
- Помогают при диагностике проблем
- Нужны для удаления/обновления программ
- Удаление нарушит механизм совместимости

### Что будет при удалении:
- ⚠️ Потеряется история всех установок
- ⚠️ Возможны проблемы с удалением программ
- ⚠️ Сброс настроек совместимости
- ️ Windows пересоздаст файлы при новых установках
