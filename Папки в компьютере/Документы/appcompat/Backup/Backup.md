## 🔍 Что это

### Функции:
- Хранение резервных копий данных совместимости
- Восстановление после сбоев Program Compatibility Assistant
- Резервное копирование настроек совместимости для конкретного пользователя
- Точки восстановления данных appcompat

### Структура файлов:
- Файлы именуются по **SID** (Security Identifier) пользователя
- Каждый пользователь имеет свой уникальный идентификатор
- Содержат резервные копии баз данных совместимости

## ⚠️ Безопасность

### Можно ли удалять?
**❌ НЕТ!** Системная папка с резервными копиями.

### Почему нельзя:
- Необходимы для восстановления данных совместимости
- Могут понадобиться при проблемах с Program Compatibility Assistant
- Удаление может нарушить механизм отката
- Потеряются резервные копии настроек
