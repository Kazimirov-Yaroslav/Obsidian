# 📁 UA

## 🎯 Основное назначение
**User Agent** — данные о пользовательском агенте, иконках приложений и телеметрии для механизма совместимости.

## 🔍 Что это

### Функции:
- Хранение информации о User Agent
- Идентификация системы для веб-приложений
- Данные о браузере и ОС для совместимости
- Иконки приложений для отображения в интерфейсе
- Настройки совместимости веб-компонентов

### Когда используется:
- При работе Internet Explorer / Edge
- При запуске веб-приложений
- При проверке совместимости браузеров
- Для корректной работы веб-компонентов Windows

---

## ⚠️ Безопасность

### Можно ли удалять?
**❌ НЕТ!** Системные данные идентификации.

### Почему нельзя:
- Необходимы для работы браузеров
- Влияют на отображение веб-сайтов
- Могут нарушиться веб-приложения
- Системный компонент
