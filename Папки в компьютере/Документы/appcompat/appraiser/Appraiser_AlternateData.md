## 🔍 Детали

### Формат CAB:
- **Cabinet file** — стандартный формат сжатия Microsoft
- Используется для упаковки системных файлов
- Поддерживает сжатие без потерь
- Часто используется для обновлений Windows

### Происхождение:
- Создаётся компонентом Application Compatibility Appraiser
- Обновляется при запуске диагностики
- Используется для отправки данных в Microsoft
