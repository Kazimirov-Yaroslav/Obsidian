## 🔍 Что это

### Функции:
- **Application Compatibility Appraiser** — сбор данных о системе
- Анализ установленных программ
- Оценка совместимости с Windows Update
- Подготовка отчётов для Microsoft Compatibility Database
- Проверка оборудования на совместимость

### Когда работает:
- При запуске Windows Update
- Периодически по расписанию (Task Scheduler)
- При установке крупных обновлений Windows
- При запуске Program Compatibility Assistant

## ⚠️ Безопасность

### Можно ли удалять?
**❌ НЕТ!** Системный компонент.

### Почему нельзя:
- Необходим для оценки совместимости перед обновлениями
- Используется Windows Update
- Может нарушиться процесс обновления системы
- Windows пересоздаст папку автоматически
